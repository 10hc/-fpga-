## Independent JPEG Group (libjpeg) and libjpeg-turbo

**This software is based in part on the work of the Independent JPEG Group.**

The decoder is written from the JPEG standard (ITU-T T.81 | ISO/IEC 10918-1). The standard
fixes the bitstream, the Huffman decoding procedures (Annex C, F.2.2) and the mathematical
inverse DCT, but not the integer arithmetic of the IDCT, of the YCbCr->RGB conversion or of
chroma upsampling. So that its pixels are bit-identical to the decoders most software uses
(libjpeg's `djpeg`, and Pillow / OpenCV through libjpeg-turbo), this implementation reproduces
the integer arithmetic of the following routines. No libjpeg source code is included; the
hardware and the Python reference model are independent implementations of the same arithmetic.

| this project | reproduces the arithmetic of |
|---|---|
| `rtl/jpeg_idct.sv`, `rtl/jpeg_idct_fast.sv` | libjpeg `jidctint.c`, `jpeg_idct_islow` (CONST_BITS = 13, PASS1_BITS = 2, its rounding and range limiting). Its factorisation is from C. Loeffler, A. Ligtenberg, G. Moschytz, "Practical Fast 1-D DCT Algorithms with 11 Multiplications", Proc. ICASSP 1989 |
| `rtl/jpeg_ycc2rgb.sv`, `rtl/jpeg_mcuout.sv` | libjpeg `jdcolor.c`, `ycc_rgb_convert` / `build_ycc_rgb_table` (SCALEBITS = 16), with the libjpeg 9 and the libjpeg 6b / libjpeg-turbo Cb->G constant |
| `rtl/jpeg_raster.sv`, `rtl/jpeg_raster_fast.sv` (`FANCY_UPSAMPLE=1`) | libjpeg-turbo `jdsample.c`, `h2v1_fancy_upsample` / `h2v2_fancy_upsample` (triangle filter, rounding biases, narrow-image fallback) |
| `model/jpeg_golden.py` | all of the above, as the bit-exact reference model used by the testbenches |

libjpeg is copyright (C) 1991-2022 Thomas G. Lane, Guido Vollbeding, distributed under the IJG

## Tools used for verification (not included, not required to use the library)

- Verilator (LGPL-3.0 / Artistic-2.0), Python 3, Pillow, NumPy, OpenCV, libjpeg 9e and
  libjpeg-turbo `djpeg`, FFmpeg and stb_image (benchmarks only), sv2v and Yosys (portability
  check).
- Intel/Altera Quartus II 13.0sp1 for the Cyclone II builds. Files that Quartus generates
  (databases, reports, netlists, timing and programming files) are build outputs and are not
  part of the sources; see `.gitignore`.
- `boards/ep2c5/gate_level/verilator/cycloneii_cells.v` (development branch) contains independent behavioural models of the Cyclone II
  cells used by Quartus netlists, written for this project from the Cyclone II Device Handbook.

## Test images

The photos in `test_images/` were taken by the project owner, Meraj Hasan, and are distributed with
this project under the same licence. The test corpus `tb/corpus/*.jpg` is generated by
`scripts/make_corpus.py` from one of them, `test_images/adapter.jpg` (metadata stripped); every
file's settings are listed in `tb/corpus/SOURCES.md`. The malformed files `tb/malformed/` are made
from corpus files by `tb/make_malformed.py`, and the reference outputs are computed by
`model/jpeg_golden.py`.
