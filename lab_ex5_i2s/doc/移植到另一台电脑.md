# 把本工程搬到另一台电脑继续开发 —— 操作清单

工程：`lab_ex5_i2s`（安路 EG4S20 / TD 6.2.1 / HDMI 多媒体播放）
本文件随工程一起拷贝，到了新电脑先看这里。

---

## 一、拷什么

| 内容 | 说明 |
|---|---|
| 工程目录 `lab_ex5_i2s\` | 必需。含 `src\`（RTL、约束、TD 工程、IP）与 `doc\`（脚本、生成工具、文档） |
| git 仓库（`.bundle` 或整个仓库） | 可选但强烈建议，保留提交历史 |
| TF 卡素材 | 卡根目录的 `*.bmp`、`A1.WAV`、`VIDEO.VID`；PC 端生成工具在 `doc\convert\make_video.py` |

**不要拷**（都是生成物，到新机器重新综合即可）：

```
*_Runs\        合成/布局布线产物（syn_1、phy_1、best_result…）
log\  *.log  *.qor  *.area  *.vcd  *.wlf  *.dath
**\__pycache__\
演示视频\      （演示录像，与工程无关，约 250MB）
doc\convert\*.VID   （视频素材，需要时用 make_video.py 重新生成）
```

一键打包（本机执行）：

```powershell
powershell -ExecutionPolicy Bypass -File D:\deepwork\tools\export_project.ps1
```

产物在 `D:\deepwork\_export\`：`*.zip`（工程本体）+ `*.bundle`（git 历史）。

## 二、新电脑要装什么

1. **安路 TD 6.2.1**（版本尽量与本机一致）
   - 若打开时报 IP 版本不兼容：删掉 `src\td_project\al_ip\` 下的 IP，用 TD 重新生成（PLL / SDRAM / HDMI TX / 音频 PLL）。
2. **TD license**：安路的 license 常与本机绑定，换机需重新申请/激活。
3. **下载器 USB 驱动**（Anlogic USB Cable）：插上板子后，设备管理器里能看到 `Anlogic usb cable` 才算装好。

## 三、放到哪个目录

解压到**纯英文、无空格**的路径，例如 `D:\work\lab_ex5_i2s`。

> TD 对路径敏感：中文路径、桌面、"文档"目录都可能引发找不到文件或综合失败。

## 四、第一次打开的最小验证

1. 双击 `src\td_project\HDMI1.4b_Transmitter_v1.0.al`；
2. 左侧文件列表应有 **53 个文件**，无红叉（红叉 = 文件缺失）；
3. 点 **综合** → 全编译 → 下载。
   - ⚠️ 只点"布局布线"会沿用旧网表，**改过代码必须点【综合】**。

## 五、这台机器上踩过的坑（务必知道）

1. **`import\` 副本陷阱**
   TD 实际编译的是 `src\td_project\import\wav_audio.v` 和 `import\key_short_long.v` —— 它们只是 `hdl_source\` 下同名文件的**副本**。改了源文件必须同步副本，否则不生效：

   ```bat
   copy /Y src\user_source\hdl_source\wav_audio.v      src\td_project\import\wav_audio.v
   copy /Y src\user_source\hdl_source\key_short_long.v src\td_project\import\key_short_long.v
   ```

   而 `video_player.v` 是直接引用（不在 import 里），属于不对称设置，别搞混。

2. **TD 会重写 `.al`**
   手工编辑 `.al` 前必须**关闭 TD**，否则退出时被覆盖。

3. **mslice 上限 4900**
   不要把大数组写成分布式 RAM。曾经把 `reg [31:0] buf [0:4095]`（16KB）直接写进逻辑，综合报
   `Design's mslice number = 6626, exceeds the limit 4900`。大缓冲请用块 RAM（BRAM9K 还剩 43 个）。

4. **多驱动错误只有综合器会报**
   `ERROR: net 'x' is constantly driven from multiple places` —— ModelSim **不报**（同一信号在两个 always 块里被赋值）。改代码后先跑：

   ```powershell
   powershell -ExecutionPolicy Bypass -File doc\tools\prebuild_check.ps1
   ```

   它会检查：`import` 副本一致性、跨 always 多驱动、`.al` 里文件是否齐全。

5. **综合前建议跑的检查**

   ```powershell
   python doc\tools\scan_multi_driver.py <RTL 目录>     # 多驱动扫描
   python doc\tools\check_sd_card.py                    # 校验 TF 卡内素材（插读卡器后）
   ```
