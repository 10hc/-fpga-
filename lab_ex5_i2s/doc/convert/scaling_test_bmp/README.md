# FPGA 自适应缩放上板素材

仅将 `0.BMP`～`3.BMP` 放入用于测试的 FAT32 卡根目录。这四张 BMP 保留原始分辨率；缩放、居中和黑边由 FPGA 完成。目录中的 PNG 是电脑生成的预期效果图，仅用于对照。

| 文件 | BMP 原尺寸 | 预期有效画面 | 检查点 |
|---|---|---|---|
| 0.BMP | 320×240 | 640×480 | 放大、满屏、圆形比例正确 |
| 1.BMP | 1920×1080 | 640×360 | 缩小，上下各 60 行黑边 |
| 2.BMP | 241×479，负高度 | 241×480 | 竖图，左 199 / 右 200 列黑边，TOP 朝上 |
| 3.BMP | 641×481 | 639×480 | 缩小，左 0 / 右 1 列黑边，行补齐无彩色斜线 |

四角分别为红、绿、蓝、黄，文字 TOP 和 BOTTOM 用于检查方向。保持卡中文件连续存储；文件碎片仍不支持。若已有四张 BMP，先在电脑上保留原文件或使用另一张卡，确保实际扫描到的是测试素材。

先从 TD 工程文件重新执行综合、布局布线和位流生成，再下载。依次检查手动切图、自动轮播和转场，随后切换视频并切回图片。`expected_all.png` 为四张预期画面的拼图。

若 TD 报 `bmp_scale is a black box`，在当前打开工程的设计源列表中添加 `src/user_source/hdl_source/bmp_scale.v`，并确认该文件用于综合，再保存工程、重新综合。TD 若一直保留旧工程会话，保存时可能覆盖磁盘上新增的源文件条目；仅修改磁盘 `.al` 后继续使用旧会话可能再次漏编。

重新生成：在工程目录运行 `python doc/tools/make_scaling_demo.py`，需要 Pillow。脚本只写本目录，不访问 SD 卡。
