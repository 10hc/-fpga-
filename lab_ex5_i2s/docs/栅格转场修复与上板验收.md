# 栅格转场恢复与上板验收

日期：2026-10-31。状态：RTL 已加固并恢复启用，独立 TD 位流已生成，待用户上板确认。

## 改动与依据

原 `trans_ctrl.v` 只轮换滑动与淡入淡出，栅格因早期上板花屏被停用。本次恢复 `滑动 → 栅格 → 淡入淡出 → 滑动` 的轮换；复位后第一张图片直接显示，第一次成功切图为栅格，随后为淡入淡出、滑动。

早期归档 TD 报告存在 `grid_col_block → App_rd_addr_r` 的 8 级组合路径，slack 为 −0.064 ns。该归档报告尚不能绑定到当时实际烧录的位流，因此不能据此认定历史花屏的唯一根因。当前版本的原地址算法在全部有效进度下没有复现地址错误。

本次将 `frame_fifo_read.v` 中栅格的两张图片地址分别用寄存器递增，将选源位 `grid_use_new` 仅在 16 像素块边界、行边界更新，拆开对角比较和宽地址运算。栅格仍为 16×16 像素、40×30 个块，按 `块行号 + 块列号 < 进度` 揭示新图；进度 0 全旧图，69 全新图。每帧只读一次 307,200 个像素，不增加帧缓存或双图读取带宽。

保留现有图片缓冲区请求/完成握手与视频模式取消逻辑：转场结束后的下一次完整读帧结束才释放旧缓冲；进入视频后取消已锁存的图片映射，视频按四缓冲线性读出。

## TD 时序结论与边界

新 `final_timing.rpt` 中 `ext_mem_clk → ext_mem_clk` 的统计为 setup WNS **+0.095 ns**、0 个违例端点，共 1,133 个端点；该时钟域包含栅格选源、地址递增与 SDRAM 应用侧地址采样。此结果支持本次对读地址路径的加固，但裕量较小，仍需上板观察。

定向报告中 `grid_use_new` 输入路径 setup **+0.914 ns**、hold **+0.708 ns**。专项脚本及报告位于任务目录 `grid_timing_probe.tcl`、`grid_probe_report.md`；因 TD 的逻辑寄存器到物理节点映射会混入上游起点，不将其他定向报告的汇总值宣称为栅格专属最差裕量。

全工程仍未完成时序收敛：全局 setup WNS **−6.699 ns**、TNS **−313.699 ns**；SD 时钟域 WNS **−1.631 ns**，相比 build6 的 −0.723 ns 变差。全局 hold WNS **+0.004 ns**、无 hold 违例。原有 SiP 位置调整与局部时钟布线 critical warning 仍存在。不能将本位流宣称为全时序通过或已完成实板稳定性认证。

## 上板验收

1. 保留现有 TF 卡内容，准备至少两张差异明显的可识别 BMP。烧录本页列出的 `grid_transition.bit`；本修改不需要重新格式化 TF 卡。
2. 复位并等待首图正常显示。用现有“下一张”操作切图，或开启自动轮播。第一次切图应出现从左上到右下的方块揭示；再切两次依次看到淡入淡出、滑动。
3. 连续观察至少 20 次切图：起始应为完整旧图，结束为完整新图，不能出现随机色块、行错位、短暂旧图回闪或永久停留。
4. 在栅格播放到一半时长按 key2 进入视频，检查视频持续更新而非卡第一帧；再长按返回图片，首图正常、下一次切图正常。重复至少 10 次，并分别在淡入淡出和滑动中重复。
5. 开自动轮播持续运行 10 分钟，同时检查音频、OSD、亮度/对比度及 Sobel 开关。快速按键时允许等待当前加载/转场完成，不应永久卡住或破坏图像。

通过以上实板验收后，可将栅格加入正式演示；在此之前，build6 仍作为已经验证过的回退版本。
