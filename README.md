# 基于安路 EG4S20 的 HDMI 多媒体播放系统（稳定版）

全国大学生嵌入式芯片与系统设计竞赛 · FPGA 创新设计赛道 · 选题一

## 本版本定位

**稳定可上板版本**。以竞赛例程 `lab_ex5_i2s` 原始代码为显示路径基础
（TF 卡扇区扫描 → SDRAM 双缓冲 → HDMI 输出），在其上叠加了
OSD 字幕与亮度/对比度调节，**已实测上板出图正常**。

> 带转场效果 / WAV 播放 / FAT32 扫描的实验版本见另一仓库
> （对应 `example_ref/lab_ex5_i2s`），该版本图片显示路径仍有问题，
> 不要用于最终演示。

## 已实现功能

| 功能 | 说明 |
|---|---|
| TF 卡 BMP 图片显示 | 640×480、24 位、未压缩；双缓冲，切换无撕裂 |
| 图片切换 | KEY2 手动切下一张；KEY4 自动轮播开关 |
| **OSD 字幕条** | 屏幕底部黑底白字，**横向滚动弹幕**，文字/速度/位置可调 |
| **亮度 / 对比度调节** | KEY3 短按循环亮度，长按（>1s）循环对比度 |
| **花样转场** | 每次切图自动轮换效果：**滑动 → 栅格 → 淡入淡出 → 滑动 …** |
| 状态色诊断 | 未出图时背景色指示加载状态，便于定位问题 |

## 花样转场说明

每次切换图片时自动按顺序轮换一种转场效果（`trans_ctrl.v`）：

| 效果 | 表现 | 参数（`trans_ctrl.v`） |
|---|---|---|
| **滑动** | 旧图向左推出，新图从右侧推入 | `SLIDE_STEP` 每帧前进像素（8 ≈ 1.3 秒） |
| **栅格** | 16×16 像素方块按对角线依次翻转成新图 | `GRID_STEP` 每帧前进对角档（2 ≈ 0.6 秒） |
| **淡入淡出** | 旧图淡出到黑，再从黑淡入新图 | `FADE_STEP` 每帧因子增量（16 ≈ 每段 0.27 秒） |

实现原理：`frame_fifo_read.v` 在**读地址层面**按行/块选择"旧图缓冲区"或"新图缓冲区"，
单读端口即可实现新旧画面对比；`video_fade.v` 在视频输出侧做乘法淡变（纯组合，0 延迟）。

> 安全性：已验证 `trans_en=0` 时读地址序列与例程原版**逐字节一致**，
> 转场逻辑不会影响正常显示路径。

## 按键与开关

| 操作 | 功能 |
|---|---|
| KEY2（B2） | 手动切换下一张图片 |
| KEY4（C1） | 自动轮播 开 / 关 |
| KEY3（B1） | **短按**：亮度循环（正常 → +80 → −40 → +40）<br>**长按**：对比度循环（1.0× → 1.5× → 0.75× → 1.25×） |
| SW1~SW4（C8/C7/C6/C5） | 拨码开关调亮度/对比度（**注意**：该引脚与 SD 卡数据线复用，受板上 SEL 跳线影响，可能无效） |

## 状态色诊断（未出图时的背景色）

| 颜色 | state_code | 含义 |
|---|---|---|
| 🔴 红 | 0 | SD 卡未初始化 |
| 🟢 绿 | 1 | 空闲（扫描完成但未找到图片） |
| 🔵 蓝 | 2 | 正在扫描扇区 / 读 BMP 头（**正常，等待即可**） |
| 🟣 紫 | 3 | 等待写入 SDRAM |
| 🩵 青 | 4 | 正在加载图像数据 |
| ⚫ 黑 | — | 图像已提交（display_valid=1） |

> 开机后背景为蓝色属正常现象：例程从扇区 0 逐个扫描 BMP 魔数，
> 图片位置越靠后等待越久（扫描范围 64MB，最坏约 26 秒）。
> ⚠️ **不要把扫描范围调小**：大容量卡的 FAT32 元数据（保留扇区 + FAT 表）
> 可能占满前 16MB，图片数据会落在 16MB 之后（实测某 16GB 卡数据区起始于
> 扇区 32768，三张 BMP 分别在 33968 / 35776 / 37584），改小就会"扫不到图"。

## 编译与下载

1. 用 **Anlogic TD 6.2.1** 打开：
   `src/td_project/HDMI1.4b_Transmitter_v1.0.al`
2. 点 **全编译**（Full Compile，会依次跑 综合 → 布局布线 → 生成比特流）
   > ⚠️ 改完源码后**必须全编译**。只点"布局布线"会复用旧网表，改动不生效。
3. 下载生成的 bit：
   `src/td_project/HDMI1.4b_Transmitter_v1.0_Runs/phy_1/HDMI1.4b_Transmitter_v1.0.bit`
4. HDMI 线插开发板 **HDMI_B** 口。

> ⚠️ 新增源文件时：必须先在 TD 里用 `Project → Add/Remove Files` 加入文件列表，
> 或**关闭 TD** 后再改 `.al`（TD 运行时会在退出时覆盖 `.al`）。

## 可调参数

| 文件 | 参数 | 作用 |
|---|---|---|
| `osd_overlay.v` | `OSD_TEXT` | 字幕文字（**必须恰好 TEXT_LEN 个字符**，不足补空格） |
| `osd_overlay.v` | `SCROLL_STEP` | 滚动速度（默认 2 像素/帧） |
| `osd_overlay.v` | `BAR_Y` | 字幕条垂直位置（默认 456） |
| `osd_overlay.v` | `TEXT_LEN` | 文本长度，须为 2 的幂 |
| `video_adjust.v` | `bright` / `gain` 表 | 亮度偏移（−255~+255）与对比度增益（128 = 1.0×） |
| `top_tf_hdmi_audio.v` | `SCAN_MAX_SECTOR` | 扫描范围（131071 扇区 = 64MB，**不要调小**） |

## 素材准备

图片需转为 **640×480、24 位、不压缩 BMP**，并用 `doc/convert/` 下的脚本
连续写入 TF 卡（依赖扇区连续存放，才能被扇区扫描方式找到）。
